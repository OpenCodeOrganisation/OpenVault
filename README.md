# OpenVault

A simple, open-source password manager for everyone.

OpenVault is a lightweight password manager designed to help users securely store and manage passwords, notes, and credentials locally.

## Features (Planned)

- Secure local password storage
- Master password derivation
- Categorized vault entries
- Password generator and strength checker
- REST API and local web dashboard
- Docker support

## Getting Started

```bash
git clone https://github.com/OpenCodeOrganisation/OpenVault.git
cd OpenVault
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python -m app.main
```
