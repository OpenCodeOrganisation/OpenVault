# Security Policy

## Supported Versions

The following versions of OpenVault currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| < 0.4   | :x:                |

## Reporting a Vulnerability

The OpenVault team takes security issues seriously. If you find a potential vulnerability in OpenVault, please report it responsibly:

1. **Do not** disclose vulnerabilities publicly via GitHub Issues.
2. Email the maintainers directly at `security@openvault.org`.
3. Provide detailed steps to reproduce the issue, along with an impact assessment.
4. We aim to acknowledge receipt within 48 hours and coordinate a fix release.

Thank you for helping keep OpenVault secure!
