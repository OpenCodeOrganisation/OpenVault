# OpenVault

A simple, open-source password manager for everyone.

OpenVault is a lightweight password manager designed to help users securely store and manage their passwords, notes, and other sensitive information.

## Features

- Secure password storage
- Password generation
- Encrypted vault
- Simple command-line interface
- Local vault management
- Import and export support
- Lightweight and easy to use

## Getting Started

Clone the repository:

```bash
git clone https://github.com/openvault/openvault.git
cd openvault
```
