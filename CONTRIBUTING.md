# Contributing to OpenVault

Thank you for your interest in contributing to OpenVault! We welcome contributions from developers of all experience levels.

## Code of Conduct

Be kind, constructive, and respectful. We are students and open-source contributors learning together.

## How Can I Contribute?

- **Reporting Bugs**: Check existing issues first. If not found, open a report using our Bug Report template.
- **Suggesting Features**: Open a feature request explaining the use case and proposed design.
- **Code Contributions**:
  1. Fork the repo and create a branch from `main`.
  2. Implement your changes with clear commits.
  3. Ensure all tests pass: `pytest`.
  4. Submit a Pull Request describing your solution.

## Code Style

- Keep functions modular and readable.
- Add unit tests for new features under `tests/`.
- Preserve docstrings and helpful comments.
